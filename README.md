# Product Information System (Desain)

Mini Project 1 - Product Information System.

## Deskripsi

Product Information System adalah aplikasi sederhana berbasis PHP yang digunakan untuk menampilkan informasi produk.

Project ini dibuat untuk menerapkan konsep dasar pemrograman PHP dengan pemisahan menjadi tiga layer, yaitu:

- Data Layer
- Processing Layer
- Presentation Layer

## Tujuan

Project ini bertujuan untuk menerapkan:

- Array
- Multidimensional Array
- Function
- Perulangan `foreach`
- `require_once`
- HTML
- CSS
- Pemisahan Data Layer, Processing Layer, dan Presentation Layer
